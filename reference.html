AI N-88 BASIC / BROWSER EDITION

命令リファレンス

このブラウザ版で使える命令・関数の手引き。書式、入力例、実装上の制限をまとめました。

BASIC画面を開く ↗

最初に

黒い画面では、行番号なしならその場で実行、行番号付きならプログラムへ登録します。登録後は RUN で実行。LIST で表示し、↑↓で行を選んで編集、Enterで確定できます。停止はCtrl+CまたはEscです。

書式の [ ] は省略可能な部分で、角括弧そのものは入力しません。「例」は行番号付きならプログラムとして登録し、それ以外は1行ずつ入力してください。管理命令は即時モードで単独入力します。

実行速度はヘッダで調整できます。標準は「実機風 ×1」、×0.25〜×4と「高速」を選択でき、設定は保存されます。特定機種の実測値による再現ではなく体感速度の目安です。SLEEPの指定時間は倍率によって変えません。

変数・式・画面の基本

大文字・小文字は区別しません。文字列は二重引用符で囲みます。変数は数値、末尾$は文字列、%は整数、!・#は数値です。未代入は0または空文字。通常の数値計算はJavaScriptの倍精度です。

種類記法
算術+ - * / \ ^ MOD（\は整数除算、^は累乗）
比較= <> < > <= >=（真は−1、偽は0）
論理NOT AND OR XOR EQV IMP（ビット演算）
数値定数123、1.5、1E3、&HFF、&O77
連結文字列の連結は+。1行に複数命令を書く区切りはコロン。
座標図形：x=0〜639 / y=0〜399。文字：桁=0〜79 / 行=0〜24。左上が原点。
色番号0 黒 / 1 青 / 2 赤 / 3 紫 / 4 緑 / 5 水色 / 6 黄 / 7 白

通常は累乗、乗除算、加減算、比較、論理演算の順に評価します。迷う場合は括弧で明示してください。文字列関数はUTF-16単位で処理し、実機のShift JISとは異なります。

エラーと互換性

未定義・未対応の命令は Syntax error。保存プログラムなら Syntax error in 20 のように行番号が付き、入力待ちへ戻ります。その他のエラーは現在、日本語の説明を表示します。

SCREEN / WIDTHは受理のみ。CONT、AUTO、ON ERROR、OPEN/CLOSE、PRINT#、PLAY、機械語・実機ハードウェア操作は未対応です。すべてのN88-BASICプログラムがそのまま動くわけではありません。

SAVEはブラウザ内の保存です。保存データを消すと失われます。PC上の.basファイルに残すには編集画面の「保存 ↓」を使ってください。起動時の67108864 Bytes freeは固定表示であり、実際の空き容量の計測値ではありません。

編集・保存#

RUN

書式

RUN [行番号または*ラベル]

プログラムを先頭または指定行から実行します。変数・配列・型宣言・関数定義を初期化します。

例

RUN 100

即時専用。指定行は存在する必要があります。

編集・保存#

LIST

書式

LIST [開始-終了]

保存されているプログラムを行番号順に表示します。

例

LIST
LIST 100
LIST 100-200
LIST -100
LIST 100-

即時専用。表示した行へ↑↓で移動して編集し、Enterで確定できます。

NEW

書式

NEW

プログラムと変数を消去します。

例

NEW

即時専用。必要なプログラムは先にSAVEしてください。

CLEAR

書式

CLEAR

プログラムを残して変数・配列・型宣言・関数定義とDATAの読込位置を初期化します。

例

例

編集・保存#

RENUM

書式

RENUM [新行番号][,[旧開始行番号][,増分]]

行番号とGOTO・GOSUB・ON・THEN/ELSE・RESTORE等の数値参照を更新します。省略値は10、全体、10刻みです。

例

RENUM
RENUM 100,,5
RENUM 1000,200,10

即時専用。新番号1〜65529、増分1以上。文字列・REM・DATAの数字は保持。参照先不明・番号衝突・逆転・上限超過は変更せずエラー。変数を初期化します。

SAVE

書式

SAVE "名前"[,A]

例

SAVE "GAME"

即時専用。同じブラウザ・同じオリジンのlocalStorage。Aの有無で形式は変わりません。PCのファイルには保存しません。

FILES

FILES

FILES

表示・入力#

PRINT / ?

書式

PRINT [式[; または , 式]…][; または ,]

値を表示して改行します。セミコロンは連続表示、カンマは空白8個。末尾に区切りを置くと改行を抑えます。

例

PRINT "こんにちは"
? 1+2
PRINT "A=";10;

カンマは実機のタブゾーンを再現せず固定8空白です。

表示・入力#

PRINT USING

書式

PRINT USING 書式文字列;値[;値…]

#で数値の桁、小数点、桁区切り、符号を指定します。!は1文字、&は全文字、バックスラッシュで空白を囲むと固定幅文字列です。

例

PRINT USING "###.##";12.3
PRINT USING "! &";"ABC";"日本語"

小数例の出力は「 12.30」。数値が幅を超えると%を付けます。通貨・指数書式は未対応。

INPUT ["案内";]変数[,変数…]

例

文字列をそのまま1行読む場合はLINE INPUT。Ctrl+Cで中断できます。

書式

LINE INPUT ["案内";]文字列変数

例

表示・入力#

CLS

書式

CLS [モード]

文字と図形を選んで消去します。省略または1は文字、2は図形、3は両方です。

例

CLS
CLS 2
CLS 3

文字消去時はカーソルを左上へ戻します。2では文字とカーソルを保持。ヘッダは消えません。

COLOR

書式

COLOR 色番号

以降の文字と、色を省略した図形の色を指定します。

例

COLOR 4:PRINT "GREEN"

0〜7を使います。追加の背景色・パレット引数は反映しません。

表示・入力#

LOCATE

書式

LOCATE 桁[,行]

文字カーソルを移動します。桁0〜79、行0〜24。行を省略すると現在行です。

例

LOCATE 10,5:PRINT "HELLO"

範囲外は画面内に丸めます。桁を空欄にする形式やカーソル表示指定は未対応。

表示・入力#

SPC / TAB

書式

SPC(空白数) / TAB(桁)

PRINTで空白を挿入します。TABは指定桁まで進み、現在より左なら改行して進みます。

例

PRINT "A";SPC(3);"B"
PRINT TAB(10);"TITLE"

SPCは0〜1000、TABは0〜79。この実装の桁は0始まりです。

表示・入力#

POS / CSRLIN

書式

POS(0) / CSRLIN

現在の文字カーソルの桁・行を返します。

例

LOCATE 5,3:PRINT POS(0);CSRLIN

0始まり。POSは引数が必要ですが値は使いません。

制御#

LET

書式

[LET] 変数=式

変数または配列要素へ値を代入します。

例

A=10
LET N$="日本語"

文字列変数には文字列、数値変数には数値を代入します。

制御#

REM / '

書式

REM コメント / ' コメント

その行の残りをコメントとして扱います。

例

10 REM 説明
20 A=1:REM 初期値

コメント内のコロン以降も実行しません。

制御#

IF / THEN / ELSE

書式

IF 条件 THEN 命令・行番号・*ラベル [ELSE 命令・行番号・*ラベル]

条件が0でなければTHEN側、0ならELSE側を実行します。

例

10 IF A>0 THEN PRINT "YES" ELSE PRINT "NO"
20 IF A=0 THEN 100
100 END

1行形式のみ。THEN側のコロン連結も条件の対象です。複数行IFや複雑な入れ子は未対応。

制御#

GOTO

書式

GOTO 行番号または*ラベル

指定した保存プログラムの行へ移動します。

例

10 PRINT "LOOP"
20 GOTO 10

行番号または定義済みラベルを指定します。Ctrl+Cで停止できます。

制御#

GOSUB / RETURN

書式

GOSUB 行番号または*ラベル / RETURN

サブルーチンを呼び出し、RETURNで呼び出し直後へ戻ります。

例

10 GOSUB 100
20 END
100 PRINT "SUB"
110 RETURN

RETURNの行番号指定は未対応。サブルーチンへの自然な流れ込みを避けるためENDを置きます。

制御#

ON GOTO / ON GOSUB

書式

ON 式 GOTO 行1,行2,… / ON 式 GOSUB 行1,行2,…

式の値が1なら行1、2なら行2を選びます。

例

10 ON 2 GOSUB 100,200
20 END
100 PRINT "ONE":RETURN
200 PRINT "TWO":RETURN

値は小数を切り捨て、0〜255。0または候補数を超える場合は次へ進みます。ON ERRORは未対応。 移動先には*ラベルも指定でき、行番号と混在できます。

制御#

FOR / NEXT

書式

FOR 変数=開始 TO 終了 [STEP 増分] / NEXT [変数[,変数…]]

指定範囲で繰り返します。STEP省略は1、負数も指定できます。

例

FOR I=1 TO 3:PRINT I:NEXT I

STEP 0はエラー。入れ子に対応。即時モードではFORとNEXTを同じ入力内に書きます。

制御#

WHILE / WEND

書式

WHILE 条件 / WEND

条件が0でない間、繰り返します。

例

10 WHILE I<3
20 PRINT I:I=I+1
30 WEND

入れ子に対応。即時モードではWHILEとWENDを同じ入力内に書きます。

制御#

END / STOP

書式

END / STOP

現在の実行を終了します。

例

10 PRINT "DONE"
20 END

この版のSTOPも終了扱いです。CONTによる再開は未対応。変数は終了後も参照できます。

制御#

DEF FN

書式

DEF FN名前(引数[,引数…])=式

式からなる関数を定義します。呼び出し中のみ引数の変数を置き換え、終了時に戻します。

例

DEF FNSQ(X)=X*X:PRINT FNSQ(12)

関数名はFNで始めます。定義・呼び出しとも括弧が必要。呼び出し深さは64まで。

変数・データ#

DIM

書式

DIM 名前(最大添字[,最大添字…])[,名前(最大添字)…]

数値・文字列の配列を宣言します。

例

DIM A(10),N$(3)
A(10)=123

既定は添字0始まり。A(10)は0〜10の11要素です。自動DIMはなく、使用前の宣言が必要。

変数・データ#

OPTION BASE

書式

OPTION BASE 0 または OPTION BASE 1

配列の最小添字を指定します。

例

OPTION BASE 1:DIM A(10)

配列を宣言する前に指定します。RUN/CLEARで0に戻ります。

変数・データ#

ERASE

書式

ERASE 配列名[,配列名…]

配列の宣言と値を消します。

例

DIM A(10):ERASE A:DIM A(20)

添字や括弧は付けません。存在しない配列はエラー。

変数・データ#

SWAP

書式

SWAP 変数1,変数2

2つの値を交換します。配列要素も使えます。

例

A=1:B=2:SWAP A,B:PRINT A;B

文字列と数値の交換はできません。

変数・データ#

DEFINT / DEFSNG / DEFDBL / DEFSTR

書式

DEF型 頭文字[-頭文字][,頭文字…]

接尾辞のない変数の既定型を頭文字で指定します。

例

DEFSTR A-C
A="文字列"

$・%・!・#の接尾辞を優先。数値型の精度を実機どおりに分ける実装ではありません。

DATA / READ

書式

DATA 値[,値…] / READ 変数[,変数…]

プログラム中のDATAを先頭から順に読みます。

例

RESTORE

書式

RESTORE [行番号または*ラベル]

例

キー・時刻#

INKEY$

書式

INKEY$

入力待ちをせず、キーを1文字取り出します。なければ空文字です。

例

10 K$=INKEY$
20 IF K$="" THEN 10
30 PRINT K$;ASC(K$)

括弧不要。実行画面をクリックしてキー入力へ。Enter=13、Backspace=8、Delete=127、右=28、左=29、上=30、下=31。Ctrl+C/Escは停止、Tabはフォーカス移動。現在の実装：キューが空でも、押している間は毎回文字を返します。リピート開始待ちはありません。複数キーでは最後に押した文字キーを優先。個別判定はKEYDOWN。実機の取得間隔との一致は未検証。

キー・時刻#

KEYDOWN

書式

KEYDOWN("キー名")

押されていれば−1、離れていれば0を返します。

例

PRINT KEYDOWN("LEFT")

ブラウザ独自拡張。LEFT/RIGHT/UP/DOWN/SPACE/ENTERや文字キー。ゲームループの中で使います。

キー・時刻#

SLEEP

書式

SLEEP ミリ秒

指定時間だけ待ち、ブラウザに処理を譲ります。

例

SLEEP 16

ブラウザ独自拡張。0〜60000。待機中もCtrl+Cで停止できます。

キー・時刻#

TIME$ / DATE$

書式

TIME$ / DATE$

マシンの現地時刻を文字列として返します。

例

PRINT TIME$;DATE$

HH:MM:SSとYYYY/MM/DD。読み取り用。代入による時計変更は未対応。

数値関数#

ABS / SGN

書式

ABS(x) / SGN(x)

絶対値と符号を返します。SGNは負数−1、0なら0、正数1です。

例

PRINT ABS(-5);SGN(-5)

数値を渡してください。

数値関数#

INT / FIX

書式

INT(x) / FIX(x)

INTは小さい方の整数へ、FIXは小数部分を0方向へ切り捨てます。

例

PRINT INT(-1.8);FIX(-1.8)

結果は−2と−1です。

数値関数#

SQR / LOG / EXP

書式

SQR(x) / LOG(x) / EXP(x)

平方根、自然対数、eのx乗を返します。

例

PRINT SQR(9);LOG(EXP(1))

SQRは0以上、LOGは正数を渡してください。定義域外やオーバーフローの診断は実機と異なります。

数値関数#

SIN / COS / TAN / ATN / PI

書式

SIN(x) / COS(x) / TAN(x) / ATN(x) / PI

三角関数と逆正接、円周率です。角度はラジアンです。

例

PRINT SIN(PI/2);COS(0);ATN(1)

PIはこの版の定数です。

数値関数#

RND / RANDOMIZE

書式

RND または RND(x) / RANDOMIZE [種]

RNDは0以上1未満の疑似乱数。正数で次の値、0で直前の値、負数で種を設定して値を返します。

例

RANDOMIZE 42:PRINT RND(1)
RANDOMIZE 42:PRINT RND(1)

同じ種なら同じ数列。種省略は現在時刻。実機と同じ数列ではありません。

数値関数#

CINT / CSNG / CDBL

書式

CINT(x) / CSNG(x) / CDBL(x)

CINTは整数丸め、CSNGは32bit浮動小数点への丸め、CDBLはJavaScript数値への変換です。

例

PRINT CINT(2.8);CSNG(1/3);CDBL(10)

CINTは−32768〜32767。丸めはMath.round相当で、実機互換ではありません。

文字列関数#

LEN

書式

LEN(文字列)

文字列の長さを返します。

例

PRINT LEN("ABC")

結果3。UnicodeのUTF-16単位で数えるため、一部の絵文字は2以上になります。

文字列関数#

LEFT$ / RIGHT$

書式

LEFT$(文字列,長さ) / RIGHT$(文字列,長さ)

左端・右端から指定長の文字列を取り出します。

例

PRINT LEFT$("ABCDE",2);RIGHT$("ABCDE",2)

長さは0以上の整数を指定してください。

文字列関数#

MID$

書式

MID$(文字列,開始[,長さ])

1始まりの位置から文字列を取り出します。長さ省略は末尾までです。

例

PRINT MID$("ABCDE",2,3)

出力BCD。UTF-16単位で扱います。

文字列関数#

MID$代入

書式

MID$(文字列変数,開始[,長さ])=文字列

元の文字列の一部を上書きします。文字列を伸ばしません。

例

A$="ABCDE":MID$(A$,2,2)="xy":PRINT A$

出力AxyDE。長さ省略は置換文字列の長さ。元の残り・指定長・置換文字列長の最小分を書き換えます。

文字列関数#

INSTR

書式

INSTR([開始,]文字列,検索文字列)

一致位置を1始まりで返します。見つからなければ0です。

例

PRINT INSTR(3,"ABABA","BA")

結果4。開始省略は1、指定範囲1〜65535。

文字列関数#

SPACE$ / STRING$

書式

SPACE$(長さ) / STRING$(長さ,文字または文字コード)

空白、または指定文字を繰り返します。

例

PRINT STRING$(5,"*");SPACE$(3);"END"

SPACE$は最大1000、STRING$は0〜65535。文字列指定では先頭1単位のみ使います。

文字列関数#

ASC / CHR$

書式

ASC(文字列) / CHR$(コード)

先頭文字のコードと、コードに対応する文字を返します。

例

PRINT ASC("A");CHR$(65)

JavaScriptのUTF-16コードを使い、Shift JISや実機の文字コードを再現しません。ASCに空文字は渡さないでください。

文字列関数#

VAL / STR$

書式

VAL(文字列) / STR$(数値)

文字列先頭の数値を読む、または数値を文字列へ変換します。

例

PRINT VAL("12ABC");STR$(123)

VALはparseFloat相当で読めなければ0。STR$は正数の先頭に空白を付けません。

文字列関数#

HEX$ / OCT$

書式

HEX$(数値) / OCT$(数値)

16進・8進表記の文字列にします。

例

PRINT HEX$(255);OCT$(8)

結果FFと10。−32768〜65535、負数は16bitの表現にします。

制御#

ラベル（*名前）

書式

行番号 *名前[:命令]

移動先に名前を付けます。英字で始め、英数字・下線を使い、大文字小文字は区別しません。

例

10 *LOOP:A=A+1
20 PRINT A
30 IF A<3 THEN *LOOP

GOTO/GOSUB、IFのTHEN/ELSE、ON GOTO/GOSUB、RESTORE、即時RUNの参照先に指定可能。行番号は必要です。重複定義・未定義参照はエラー。RENUMでラベル名は変わりません。

該当する命令がありません。検索語や分類を変更してください。
