## 保持すべき挙動

- 初回起動時は空のプログラム。保存済みの `n88-source` があれば空文字も含めて復元し、サンプルを自動挿入しない。

- 画面は640×400、80桁×25行。グラフィック・確定済み文字・編集中の文字は別レイヤー。
- 入力行を黒く塗りつぶさない。`terminal-cursor.ts` は確定済み文字だけをCSS clip-pathで隠し、透明な入力Canvasに描画する。グラフィックは見えるままにする。入力が非表示になったらマスクを解除。
- 入力文字はEnter前から表示。IMEとネイティブ選択を保ち、カーソルを上下しても文字の縦位置を変えない。
- ↑↓は画面内の行編集、Alt+↑↓は履歴。行番号付き入力はEnterで登録し、`Ok`を追加しない。次の行の表示を消さない。
- Ctrl+Cは実行・INPUT・SLEEPを中断。待機中の繰り返し操作でも改行。文字選択時の通常のコピーは妨げない。
- CLS省略／1は文字のみ、2は図形のみ、3は両方。ヘッダは常時表示。
- INKEY$は現在、キューが空でも押しているキーを毎回返す実装。実機の取得間隔は未検証。KEYDOWNとSLEEPは独自拡張。
- 速度の標準は「実機風 ×1」。命令ごとの概算待機であり実測したCPU再現ではない。INPUT待ちとSLEEPは速度倍率で短縮しない。
- ラベルは行番号の後に `*NAME`。GOTO/GOSUB、IF、ON、RESTORE、RUNで使える。
- ヘッダのタイトルはトップへ戻る。従来の「コード・保存」切替ボタンは全画面では非表示。

## 保存とデータ

- localStorageキー：`n88-source`（編集中コード）、`n88-programs`（名前付き保存）、`n88-speed`（速度）。
- URLのホスト・スキーム・ポートが違うと保存領域が異なる。localhostからPagesへはファイルで移す。
- 壊れた保存データは検証エラーにし、自動的に空データで上書きしない。
- UIの上書き／読込は確認を挟む。入力中の未確定行は保存対象に含まれない。

## 未解決・未検証

1. **RNDの引数処理**：調査済みだが未修正。負の引数を `Math.trunc` するため `RND(-0.1)` と `RND(-0.9)` が同じ種になる。`RND("abc")` と `RND(1,2)` も受理する。独自の32bit線形合同法であり、実機と同じ列ではない。RND(0)は直前値。RUN時の系列初期化なども一次資料／実機で検証が必要。
2. **配列アクセスの厳密化**：`noUncheckedIndexedAccess` は全体で未有効。動的辞書はPartial、トークン読取は検証済みだが、正規表現の捕捉・画面バッファ等には整理の余地がある。非nullアサーションの大量追加で済ませない。
3. **Actionsの更新**：現在のデプロイは成功するが、一部ActionsにNode 20ランタイム非推奨の警告がある。更新する際は公式の対応バージョンを確認する。
4. 実機の数値精度・文字コード・複数パートの音楽・機械語・ディスクI/O・ROMは再現しない。文字列はUnicode。
5. 起動画面の `67108864 Bytes free` は固定の表示値で、実メモリの計測・制限ではない。

## 次の担当者の確認手順

1. `git status --short` を確認してユーザーの変更を保護。
2. `npm ci`（依存導入が必要なら）→ `npm run check`。
3. 対象の既存テストを読み、最小の再現例から修正。
4. 画面変更なら手動確認。公開の依頼があればpush後のActions・公開URLも確認。
