対応命令と使い方
行番号付きのプログラムを入力し「実行」を押してください。日本語は文字列・コメントに使えます。
実行速度
標準は「実機風 ×1」。ヘッダで×0.25〜×4、または待ち時間を加えない「高速」に変更できます。実行中も変更でき、次回起動時にも設定を保持します。単純な命令を約1ミリ秒相当として、表示・描画は重く扱う目安です。特定のPC-9801の実測値やCPUクロックを再現したものではありません。SLEEPの指定時間は倍率で変えません。
起動画面
当時のBASICの雰囲気を参考にした、非公式の独立した互換実装です。原製品の権利者による提供・公認を示すものではありません。起動メッセージは当時の表示をもとに、タイトルをAI N-88 BASIC(86)、著作権行をCopyright (C) 2026 by TYに変更したものです。67108864 Bytes freeは64 MiBを想定した固定表示で、ブラウザの実際の空き容量ではありません。使用量の計測・上限管理は未実装です。文字はブラウザの等幅フォントを使用し、実機ROMフォントではありません。全画面表示でも操作バーは画面上部に常時表示されます。
即時モード
黒い画面をクリックして直接入力できます。Enterで確定し、Backspace・Delete・左右キーで編集、↑↓で画面上の行を移動して編集できます。編集した行はEnterで確定します。Alt+↑↓で履歴を呼び出します。日本語入力と貼り付けにも対応。INPUTの回答も画面内に入力します。変数は次の命令にも引き継ぎます。RUN [行番号]：変数を初期化して実行、LIST [開始-終了]：プログラム表示、NEW：プログラムと変数を消去、CLEAR：変数のみ初期化。行番号付き入力で行を追加・置換し、行番号だけで削除します。編集はエディタと自動保存に反映され、変数は初期化されます。CONTや複数入力にまたがるFOR/NEXTは未対応です。
PLAY（基本MML）
PLAY "T120 O4 L8 CDEFGAB>C"で単音のメロディを再生します。C〜B、R（休符）、#・+・-、付点、音長、T（テンポ）、O（オクターブ）、L（既定音長）、V（音量）、<・>に対応。終了まで待ち、Ctrl+Cや停止で中断できます。各PLAYで設定を初期化。複数パート・FM音色・バックグラウンド再生は未対応です。
基本
PRINT / ?、PRINT USING、LET、INPUT、LINE INPUT、REM / '、CLS（省略 / 1：文字のみ、2：図形のみ、3：両方）、END、STOP、BEEP
ラベル
10 *LOOP のように行番号の後で定義します。10 *LOOP:PRINT "HELLO" のようにコロンで命令を続けることもできます。GOTO *LOOP、GOSUB *SUB、IF 条件 THEN *YES ELSE *NO、ON 式 GOTO / GOSUB、RESTORE *DATA、RUN *STARTに対応。名前は英字から始め、英数字・下線を使用し、大文字小文字は区別しません。RENUMでも名前は変わりません。行番号の省略はできません。
制御
GOTO、IF … THEN … ELSE、FOR … TO … STEP / NEXT、GOSUB / RETURN、ON 式 GOTO / GOSUB 行番号一覧、WHILE / WEND、DEF FNA(X)=式。NEXT J,Iのように複数のループを閉じられます。
データ
DIM、DATA / READ / RESTORE、数値変数、$ 文字列変数、% 整数変数、配列（既定は添字0から）、OPTION BASE 0 / 1、ERASE A,B、SWAP A,B、DEFINT / DEFSNG / DEFDBL / DEFSTR A-Z。!・#の数値変数にも対応します。
描画
COLOR 0〜7、LOCATE x,y、PSET (x,y),色、LINE (x1,y1)-(x2,y2),色[,B / BF]、CIRCLE (x,y),半径,色、PRESET (x,y)[,色]（既定は黒）、PAINT (x,y),色[,境界色]、POINT(x,y)（色番号、画面外は−1）。塗りつぶしは指定の境界色まで行い、文字は対象にしません。
ゲーム入力・速度
INKEY$：入力された1文字を取り出す（入力なしなら空文字）。この版ではキーを押している間、リピート開始を待たず毎回文字を返します。実機の取得間隔との一致は未検証です。Enter=13、Backspace=8、Delete=127、右=28、左=29、上=30、下=31（ASCで確認）。サンプル「INKEY$ キー入力テスト」で試せます。単独のPRINT INKEY$は待たずに終了するため、キー待ちはループで書きます。KEYDOWN("LEFT") / KEYDOWN("RIGHT") / KEYDOWN("A") など：押されていれば −1、それ以外は0。SLEEP 16：16ミリ秒待つ。KEYDOWNとSLEEPはこのブラウザ版の拡張です。ゲーム画面にフォーカスがあるときに入力を受け付けます。
関数
ABS、INT、FIX、SQR、SIN、COS、TAN、ATN、LOG、EXP、SGN、RND、LEN、VAL、STR$、CHR$、ASC、LEFT$、RIGHT$、MID$、SPACE$、INSTR([開始位置,]文字列,検索文字列)、STRING$(長さ,文字または文字コード)、HEX$、OCT$、CINT、CSNG、CDBL、SPC、TAB、POS(0)、CSRLIN、TIME$、DATE$。RANDOMIZE [種]で乱数を初期化でき、RND(0)は直前の値を返します。MID$(A$,開始[,長さ])=文字列も使えます。
演算
+ − * / \ ^ MOD、= <> < > <= >=、AND、OR、NOT、XOR、EQV、IMP。&HFF（16進数）、&O77（8進数）も使えます。
名前を付けて保存（即時モード専用）
SAVE "GAME"：現在のプログラムを保存（同名は上書き）、LOAD "GAME"：読み込み、LOAD "GAME",R：読み込んで実行、MERGE "GAME"：現在のプログラムに結合（同じ行番号は保存側を優先）、FILES：名前の一覧。SAVE "GAME",Aも同じテキスト保存です。同じブラウザ・同じURLの保存領域を使い、実機ディスクやPCのファイルにはアクセスしません。ブラウザの保存データを消すと失われます。DELETE 100-200：指定範囲のプログラム行を削除。LOADや行編集では変数を初期化します。


行番号の振り直し（即時モード）
RENUM [新行番号],[旧開始行番号],[増分]。RENUM：全体を10から10刻み、RENUM 100,,5：全体を100から5刻み、RENUM 1000,200,10：旧200行以降を1000から10刻みにします。GOTO / GOSUB、ONの行番号一覧、THEN / ELSEの行番号、RESTOREなどの参照先も更新します。文字列・REM・DATAの内容は変えません。新行番号は1〜65529。存在しない参照先、行番号の衝突・逆転・上限超過は、プログラムを変更せずエラーにします。変更後は変数を初期化します。
書式の例
PRINT USING "###.##";12.3 → 小数点以下2桁。#の数値桁、桁区切り、前後の+・末尾の−、!（1文字）、&（全文字）、バックスラッシュで囲んだ空白（固定幅）に対応。通貨・指数書式は未対応です。LINE INPUT "名前";A$はカンマや空白を含む1行をそのまま読み込みます。


実機の完全なエミュレータではありません。SCREEN / WIDTH は受理しますが、画面は640×400・80桁×25行固定です。複数パートの音楽やFM音色指定、OPEN / CLOSE / PRINT#などのファイル入出力、機械語、漢字ROM、実機固有の数値精度・文字コードは未対応です。ファイルはUTF-8を使用します。IFは1行形式のみです。SAVE / LOADなどの管理コマンドは単独で入力してください。TAB・POS・CSRLINの座標はLOCATEと同じく0始まりです。BEEPは短い単音で、音量設定やブラウザの再生制限により聞こえない場合があります。
