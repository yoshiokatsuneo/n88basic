# N88 日本語 BASIC — Browser Studio

**[ブラウザで使う → 公開Webページ](https://yoshiokatsuneo.github.io/n88basic/)**

ブラウザだけで動く、日本語表示対応のBASIC実行環境です。N88-BASICの基本命令を独立して実装しています。実機のROMを使う完全エミュレータではありません。

## 起動

`index.html` をブラウザで開くだけで利用できます。配布済みのJavaScriptで動くため、利用時のビルドや外部ライブラリの読み込みは不要です。

ローカルサーバーを使う場合は `npm start` を実行し、http://localhost:8080 を開いてください（Python 3が必要）。

## 命令リファレンス

[書式・例・制限を検索できるリファレンス](reference.html)を用意しています。全画面ヘッダの「命令リファレンス ↗」から別タブで開けます。オフラインで閲覧でき、分類絞り込みと印刷に対応しています。

編集元は docs/reference-data.json、再生成は python3 docs/build-reference.py です。

## 使い方

トップページの「Basic画面へ」を押すと、黒い画面をブラウザ全体に表示します。640×400の縦横比を保って表示し、操作バーは画面上部に常時表示され、「コード・保存」でエディタを表示できます。表示を切り替えても入力中の文字や実行状態は保持されます。

- 「コード・保存」のエディタに行番号付きのBASICを入力し、実行ボタンまたは Command / Ctrl + Enter を押します。
- INPUT実行中は実行画面の下に入力欄が表示されます。
- 停止ボタンまたは Escape で実行を停止できます。
- 編集内容はlocalStorageに自動保存します。ブラウザ設定により保存できない場合もあるため、大切なコードは保存ボタンからUTF-8の .bas ファイルで保存してください。
- サンプルはブロック崩し、日本語表示、グラフィックス、数あてゲーム、九九を収録しています。

### 全画面での保存・読み込み

ヘッダの「保存」で名前を入力すると、SAVE命令と同じブラウザ内の保存領域に保存します。「読み込み」では保存済みプログラムを一覧から選べます。同名の上書きと読み込みによる置き換えは確認してから行います。実行中は操作できません。入力中の行はEnterで登録してから保存してください。

ダイアログの「ファイルに保存 ↓」「ファイルから読み込み」ではUTF-8の .bas / .txt ファイルを扱えます。ブラウザ内の名前付き保存とは別です。閉じるとBASICの入力に戻ります。

## 即時モード（Immediate mode）

黒い実行画面をクリックするとカーソルが出ます。そのまま命令を入力してEnterを押すと、その場で実行できます。入力したコードも結果も黒い画面に表示されます。空行でEnterを押すと1行下へ移動し、最下行では画面がスクロールします。Ctrl+Cは実行中・INPUT待ち・SLEEP待機中に割り込み、Breakと表示して入力へ戻ります。エディタに行番号なしの命令を1行だけ書いて「実行」を押すこともできます。

```basic
PRINT 3333
A=10
PRINT A*2
FOR I=1 TO 3: PRINT I: NEXT I
INPUT "名前は？";N$
PRINT N$
```

Backspace・Delete・左右キーで入力中の行を編集でき、日本語IME・1行の貼り付けに対応しています。`INPUT`の回答も黒い画面上で入力します。↑↓で画面内の行へカーソルを移動し、LISTなどで表示済みの行を編集できます。Enterでその行を実行・登録します。画面上の編集だけでは保存プログラムは変更されません。移動範囲は表示中の25行です。

変数・配列は次の即時命令にも引き継ぎます。通常のプログラム終了後にも値を確認できます。描画命令も即実行でき、文字画面を消したいときは `CLS` または `CLS 1`、図形だけなら `CLS 2`、両方なら `CLS 3` を入力します。Alt+↑↓キーで入力履歴を呼び出せます（直近100件、ページ内のみ）。実行中は新しい命令を受け付けません。Ctrl+C・停止ボタン・Escapeで中断した後に続けられます。

- `10 PRINT "こんにちは"`：行を追加または置換し、エディタ・自動保存に反映
- `10`：10行を削除
- `LIST`：保存されているプログラムを表示
- `LIST 10-100` / `LIST 100` / `LIST -100` / `LIST 100-`：範囲・行を指定して表示
- `RUN` / `RUN 100`：変数を初期化して先頭・指定行から実行
- `NEW`：プログラムと変数を消去（必要なコードは先にファイルに保存）
- `CLEAR`：プログラムを残し、変数・配列を初期化

即時モードからの行編集時にも変数は初期化されます。`GOTO` / `GOSUB` はエディタの行番号へ移動でき、`READ` / `RESTORE` はそのプログラムのDATAを参照します。直接入力の `FOR/NEXT` は同じ入力内に書いてください。`CONT`、複数入力にまたがる制御構文、`RUN`などの管理コマンドと他命令のコロン連結は未対応です。変数はページの再読み込みで消えます。

## ブロック崩し

「コード・保存」のサンプルで「ブロック崩し」を選び、「開く」→「実行」で遊べます。編集中のコードは先に保存してください。ゲーム自体もBASICで書かれているため、速度やパドルの幅などを編集して遊べます。

- タイトル画面で SPACE または「発射 / START」を押して開始し、もう一度押してボールを発射します。
- ゲーム画面にフォーカスがある状態で ← → または A / D を押すと移動します。画面の左右ボタンは長押しでも操作できます。
- ブロックは24個、1個10点。残機は3つ。全破壊でクリアです。
- クリア・ゲームオーバー後は SPACE でリトライできます。Escape または「停止」で終了します。
- エディタに入力しているキーはゲームに渡しません。ゲーム画面をクリックすると操作に戻れます。

### ゲーム用の命令

`K$=INKEY$` は入力を待たずにキーを1文字取り出します。入力がなければ空文字です。ブラウザ版のキー割り当ては右=CHR$(28)、左=CHR$(29)、上=CHR$(30)、下=CHR$(31)、Enter=CHR$(13)、Backspace=CHR$(8)、Delete=CHR$(127)、SPACE=" "。このブラウザ版では、入力キューが空でもキーを押している間は毎回その文字を返します。OSのリピート開始を待ちません。複数キーでは最後に押した文字キーを優先します。N88-日本語BASIC(86)実機での長押し時の取得間隔との一致は未検証です。複数キーの個別の押下判定にはKEYDOWNを使います。

`KEYDOWN("LEFT")` はキーを押している間 −1、離すと0になります。RIGHT / UP / DOWN / SPACE / ENTER や文字キーも使えます。`SLEEP 16` は16ミリ秒待ちます（0〜60000）。待機中も停止できます。**KEYDOWNとSLEEPはこのブラウザ版の独自拡張**で、実機のN88-BASIC互換命令ではありません。

既存のN88-BASICゲームは、そのプログラムが使用する命令に依存します。INKEY$を使う簡単なゲームは移植できますが、未実装の命令、音楽やハードウェア依存の処理を含むゲームをそのまま実行できるわけではありません。

## 対応範囲

PRINT、LET、INPUT、REM、CLS、END、STOP、GOTO、1行IF/THEN/ELSE、FOR/TO/STEP/NEXT、GOSUB/RETURN、DIM、DATA/READ/RESTORE、COLOR、LOCATE、PSET、LINE（B/BF）、CIRCLE。数学関数と基本文字列関数にも対応しています。詳細は画面の「対応命令 / ヘルプ」を参照してください。

画面は640×400・80桁×25行、8色固定です。SCREEN / WIDTH は互換性のため受理しますが表示モードは変更しません。複数パートの音楽・FM音色、ディスク入出力、機械語、漢字ROM、実機特有の数値精度・文字コード、完全な構文互換性は未対応です。日本語の文字はUnicodeで表示します。既存のShift JISファイルはUTF-8に変換して読み込んでください。RNDは疑似乱数を使用し、RANDOMIZEの同じ種で同じ数列を再現できます。

## 追加した命令・関数

- 制御：ON … GOTO/GOSUB、WHILE/WEND、DEF FN、NEXT J,I
- 文字・書式：LINE INPUT、PRINT USING（数値桁・小数・桁区切り・符号・文字列）、MID$代入、INSTR、STRING$、SPC、TAB
- 型・配列：DEFINT/DEFSNG/DEFDBL/DEFSTR、OPTION BASE、ERASE、SWAP、CINT/CSNG/CDBL
- 描画・音：PRESET、PAINT、POINT、BEEP
- その他：HEX$/OCT$、&H/&O定数、RANDOMIZE、TIME$/DATE$、POS/CSRLIN、XOR/EQV/IMP
- 即時管理：SAVE "名前"、LOAD "名前"（,Rで実行）、MERGE "名前"、FILES、DELETE 開始-終了

名前付き保存は同じブラウザ・同じオリジンのlocalStorageを使います。同名へのSAVEは上書きし、MERGEは同じ行番号を保存側で置き換えます。容量不足などはエラーを表示します。実機ディスクやホストのファイル入出力ではありません。管理命令は即時モードで単独入力します。文字列はUnicode、数値は主にJavaScriptの数値で、実機の精度・文字コードを再現するものではありません。TAB・POS・CSRLINは0始まりです。PRINT USINGの通貨・指数書式は未対応です。

例（即時モードでも入力可能）：

```basic
LINE (100,100)-(220,220),7,B
PAINT (150,150),2,7
PRINT POINT(150,150)
DEF FNA(X)=X*X
PRINT FNA(12)
PRINT USING "###.##";12.3
```

## 開発（TypeScript）

エージェントによる作業は [AGENTS.md](AGENTS.md) と [引き継ぎメモ](docs/HANDOFF.md) を最初に確認してください。

Node.jsとnpmを用意し、初回に `npm ci` を実行してください。

- `npm run check`：ESLint・整形・型チェック・ビルド・全テストをまとめて実行
- `npm run lint`：危険な型操作、未処理のPromise、コーディング規約を検査
- `npm run typecheck`：strictモードで型チェック
- `npm run build`：型チェック後、ES Modulesを `dist/` へ、ブラウザ用バンドルとソースマップをルートへ生成
- `npm run watch`：編集時に型チェックとビルドを自動実行
- `npm test`：ビルドしてからインタプリタ・ゲーム・画面操作のテストを実行
- `npm run format` / `npm run format:check`：ソース・ビルドスクリプト・テストを整形／整形確認
- `npm start`：ローカルサーバーを起動（Python 3が必要）。開発中は別ターミナルで `npm run watch` を動かしてください。

編集するのは `src/` 内のTypeScriptです。ルートの `.js` と `.js.map` は生成物なので直接編集せず、ソース変更後にビルドしてください。生成物も配布することで、そのままブラウザで利用できます。ソースマップによりブラウザの開発ツールからTypeScriptを追えます。

- `src/types.ts`：BASICの値、入出力、実行結果の共通型
- `src/basic.ts`：非同期インタプリタと命令実行（eval不使用）
- `src/expression.ts` / `src/syntax.ts`：式の解析・評価と構文の共通処理
- `src/errors.ts`：BASICのエラー型
- `src/program-lines.ts`：行番号付きソースの解析
- `src/storage.ts`：保存データの読み書き・実行時検証
- `src/graphics.ts`：パレット色の判定と塗りつぶし
- `src/session.ts`：即時コマンド、行編集、保存・読み込み
- `src/keyboard.ts`：キー入力キューと押下状態
- `src/app.ts`：実行画面、エディタ、ゲーム操作
- `src/terminal-cursor.ts`：入力中の文字とカーソル描画
- `src/samples.ts`：BASICサンプル
- `src/reference.ts`：命令リファレンスの検索・絞り込み
- `index.html` / `basic.html` / `style.css`：ページと見た目
- `tests/*.test.js`：生成されたJavaScriptを検証する回帰テスト

ソースとテストはES Modulesの `import` / `export` で依存関係を明示しています。型だけの参照には `import type` を使い、`strict`・`verbatimModuleSyntax`・`isolatedModules` を有効にしています。名前空間や実行時のグローバル変数には依存しません。

`scripts/build.mjs` がesbuildでブラウザ用の3ファイル（`app.js`・`terminal-cursor.js`・`reference.js`）を生成します。ファイルを直接開く使い方を保つため、配布用バンドルだけは通常のスクリプト形式です。手書きソースでIIFEを管理する必要はありません。Node.jsのテストは `dist/` のES Modulesを読み込み、画面操作テストは実際のブラウザ用バンドルを検証します。`dist/` はビルドで再生成できます。

### 初回セットアップと起動

この環境ではNode.js 24.2.0、Python 3.14.7で動作確認しています。開発ツールのESLintはNode.js 20.19以降の20系、22.13以降の22系、または24以上を要求します。Python 3はローカル配信用です。

プロジェクトのルートで実行します。

```sh
npm ci
npm run check
npm start
```

`npm ci` はロックファイルに記録した依存関係をインストールします。`npm run check` は検査とビルドを行います。サーバーが起動したら http://127.0.0.1:8080/basic.html を開きます。`npm start` 自体はビルドしません。

開発中は別のターミナルで次を実行します。

```sh
npm run watch
```

保存すると型チェックとブラウザ用バンドルの再生成が走ります。ブラウザの自動リロードはないため、画面は手動で再読み込みしてください。watchでは型チェックとバンドル生成が並行するため、画面が動いていても型エラーが残っている場合があります。完了時には `npm run check` を実行します。watchとサーバーはそれぞれのターミナルでCtrl+Cを押して停止します。

### ブラウザでデバッグ

1. `npm run build` または `npm run watch` で最新の出力を用意し、ローカルサーバー経由でBASIC画面を開きます。
2. ブラウザの開発者ツールを開き、Sources（Safariではソース／デバッガ）でソースマップの `src/` を探します。JavaScriptソースマップが無効なら有効にします。
3. 命令の処理なら `src/basic.ts` の `statement`、式なら `src/expression.ts` の `evaluateExpression`、入力や画面なら `src/app.ts` にブレークポイントを置きます。
4. BASIC画面で `PRINT 1+2` などを入力し、停止した位置で引数・ローカル変数・呼び出し履歴を確認します。再開すると結果が表示されます。

BASIC実行中の例外は画面表示のために捕捉されます。例外の発生箇所を調べる場合は、デバッガの「捕捉された例外でも停止」を有効にします。読み込み失敗や非同期エラーはConsole、スクリプトや `.map` の取得はNetworkで確認できます。開発者ツールが使えない埋め込みブラウザでは、同じURLを通常のブラウザで開いて確認してください。

### テストで問題を絞る

全体を検証する場合は `npm run check`、テストだけなら `npm test` を実行します。個別テストを直接実行するとビルドは自動で走らないため、先にビルドしてください。

```sh
npm run build
node --test tests/labels.test.js
node --test --test-name-pattern="Ctrl.C" tests/terminal.test.js
```

テストをデバッガで止める場合は次のように起動します。Node.jsのインスペクタへ接続できるエディタやブラウザから接続し、実行を再開してください。

```sh
node --inspect-brk --enable-source-maps --test --test-concurrency=1 tests/labels.test.js
```

テストは `dist/` のES Modules、画面操作テストはルートの `app.js` を使用します。実際のブラウザの描画・IMEは自動テストだけでは確認できないため、画面でも確認してください。

### 変更が反映されない・起動できない場合

- 変更が反映されない：watchのエラーを確認し、`npm run build` を実行してからブラウザを再読み込みします。必要なら開発者ツールでキャッシュを無効にします。生成された `.js` ではなく `src/*.ts` を編集してください。
- TypeScriptが開発者ツールに出ない：`.js.map` の取得が成功しているか、ソースマップ設定が有効か確認します。ビルドし直してページを再読み込みしてください。
- 8080番ポートが使用中：既存のサーバーを利用するか、`python3 -m http.server 8081` で別のポートを使います。ポートが変わると保存領域も別になるため、保存プログラムが見えなくなります。
- 保存プログラムが見えない：`localhost` と `127.0.0.1`、HTTPとfile、ポートの違いでlocalStorageは共有されません。同じURLで開き直してください。調査のために保存領域を消す必要はありません。
- 保存データのエラー：開発者ツールのStorage／Applicationで `n88-programs` を確認します。編集・削除する前に元の文字列を控えてください。`n88-source` は編集中のコード、`n88-speed` は速度設定です。

### コーディング規約

- 条件分岐とループには波括弧を付け、再代入しない値には `const` を使います。型の参照は `import type` で宣言します。
- JSONなど外部から来るデータは `unknown` として受け、検証してから使います。不正な保存データは自動で空にせず、元データを保持したままエラーを返します。
- Promiseは待機するか、失敗時の処理を付けます。ESLintで `any` による危険な操作や未処理のPromiseを検出します。
- 動的な変数・配列・ラベル辞書は `Partial<Record<…>>` とし、キーが存在しない可能性を型で表します。式のトークンは種類ごとの型で表し、読み取り位置を検証します。
- 未使用の変数・引数、戻り値の欠落、switchの意図しないフォールスルーをコンパイラで検査します。
- `noUncheckedIndexedAccess` はまだ全体には有効化していません。正規表現の捕捉や画面バッファなどには、別途境界チェックの整理が必要です。非nullアサーションを単に増やして通す方針は取りません。
- TypeScriptはtypescript-eslintが正式対応する6.0系に固定しています。更新時は両者の互換性と `npm run check` を確認します。

## 起動画面

黒地に白文字、80桁×25行、点滅するブロックカーソルと `Ok` により、当時のBASICの雰囲気を表現しています。起動メッセージは当時の表示をもとに、タイトルをAI N-88 BASIC(86)、著作権行をCopyright (C) 2026 by TYに変更しています。67108864 Bytes freeは64 MiBを想定した固定表示であり、ブラウザの実際の空き容量ではありません。使用量の計測・上限管理は未実装です。原製品の権利者による提供・公認を示すものではありません。

ROMフォントは使用せず、ブラウザの等幅フォントで描画しているため、字形の完全再現ではありません。

### INKEY$でキーを待つ

編集画面のサンプル「INKEY$ キー入力テスト」でキーと文字コードを確認できます。実行中に黒い画面をクリックするとキー入力へフォーカスが戻ります。単独の `PRINT INKEY$` は待たずに終わるため、キー待ちはループを使います。

```basic
10 K$=INKEY$
20 IF K$="" THEN 10
30 PRINT K$;ASC(K$)
```

Enterによる確定は不要です。Ctrl+C・Escは実行停止用として予約しています。Tabはブラウザのフォーカス移動に使います。通常の文字キー入力を対象とし、日本語IMEでの文章入力にはINPUT / LINE INPUTを使ってください。

CLS 1は文字画面とカーソルを初期化し、CLS 2は図形だけを消して文字とカーソル位置を保持します。CLS 3は両方を消します。引数には1〜3の整数を返す式も指定できます。従来の引数なしCLSは両方を消していましたが、現在は文字のみです。画面クリアボタンは両方を消します。

### RENUM

即時モードで `RENUM [新行番号],[旧開始行番号],[増分]` を入力すると、行番号と参照先をまとめて更新します。

- `RENUM`：全体を10から10刻み
- `RENUM 100,,5`：全体を100から5刻み
- `RENUM 1000,200,10`：旧200行以降を1000から10刻み

GOTO/GOSUB、ONの行番号一覧、THEN/ELSEの行番号、RESTOREなどを更新し、文字列・REM・DATA中の数字は保持します。新行番号は1〜65529、増分は正の整数です。存在しない参照先や行番号の衝突・逆転・上限超過がある場合、このブラウザ版では一切変更せずエラーにします。編集結果は自動保存され、変数は初期化されます。

## 実行速度

ヘッダで「実機風 ×0.25 / ×0.5 / ×1（標準）/ ×2 / ×4 / 高速」を選べます。設定はブラウザに保存され、実行中も変更可能です。単純命令約1ms、PRINT約2ms、LINE/CIRCLE約8ms、PAINT約16msを目安に実行ペースを制限します。特定機種の実測による校正ではなく、PC-9801風の体感速度です。実際の描画量や式の複雑さによる実機の差までは再現しません。SLEEPの時間とINPUTの人間の入力待ちは倍率で短縮しません。高速では追加の速度制限を外します。

メイン画面は全画面BASICです。補助画面はコード編集・サンプル・ファイル読込・保存に絞っています。「BASIC画面へ」で即座に戻れ、補助画面の「実行」でもBASIC画面へ切り替わります。

トップページ（index.html）は短い紹介と「Basic画面へ」、リファレンスへのリンクを表示します。BASIC本体は basic.html にあり、直接開くこともできます。保存領域は同じオリジンなので、既存のプログラムと速度設定を引き継ぎます。

## ラベル

行番号の後に `*LOOP` のように定義します。名前は英字から始まる英数字・下線で、大文字小文字は区別しません。GOTO/GOSUB、IFのTHEN/ELSE、ON GOTO/GOSUB、RESTORE、即時RUNの参照先として使えます。RENUM後も名前で参照できます。

```basic
10 *LOOP:A=A+1
20 PRINT A
30 IF A<3 THEN *LOOP
```

## GitHub Pagesへの公開

`.github/workflows/pages.yml` はmainへのpush時に `npm ci`、`npm run check` を実行し、成功した場合だけGitHub Pagesへ公開します。リポジトリのSettings → Pages → SourceをGitHub Actionsに設定します。

`npm run package:site` はビルド済みのブラウザ用ファイルだけを `_site/` に集めます。単独実行する場合は先に `npm run build` を実行してください。公開物に開発環境やnode_modulesは含めません。公開先は通常 `https://所有者.github.io/リポジトリ名/` です。

公開サイトの保存領域はローカル環境と別です。手元のプログラムを移す場合は「ファイルに保存」で書き出し、公開サイトの「ファイルから読み込み」を使ってください。

## PLAY（基本MML）

```basic
PLAY "T120 O4 L8 CDEFGAB>C"
PLAY "O4 L4 C4. D8 E4 R4"
```

単音の簡易メロディに対応します。C〜B、R（休符）、#/+/-、音長1〜64、付点、T32〜255（テンポ）、O1〜8（オクターブ）、L1〜64（既定音長）、V0〜15（音量）、< >が使えます。文字列変数や連結式も指定できます。各PLAYの開始時にT120 O4 L4 V8へ戻ります。

この版では再生終了まで次の命令を待ち、Ctrl+C・Esc・停止ボタンで中断します。速度倍率は音楽のテンポに影響しません。三角波による簡易音源で、実機のFM/SSG音色や演奏タイミングの完全再現ではありません。複数パート、バックグラウンド再生、音色指定、タイ、マクロ展開は未対応で、未対応指定はエラーにします。1回の上限は4096文字・10分です。音が出ない場合はブラウザ・端末のミュートや音声再生の許可を確認してください。

実装は `src/music.ts`。音符の解析とWeb Audioの再生・中断を分離し、`tests/music.test.js`で検証しています。
